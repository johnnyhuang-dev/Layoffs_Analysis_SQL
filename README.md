# Layoffs_Analysis_SQL
Repo storing my project of cleaning and analyzing some messy data on worldwide layoffs to figure out what companies and sectors are the best to invest in based on their job volatility. I wanted to learn about layoff trends in the past few years and ended up finding relevant information that could guide individuals and VC companies in investments.
If you would like to know more about how I made this, check out the documents or send me a message and we can have a chat.
